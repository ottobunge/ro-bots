## User direction

The user accepts a uaRO-like starting world and incremental additions on the
server side. Exact replication of every custom system is not the finite MVP gate.
The original goal remains a human-playable private world populated by isolated,
ordinary-player agents, with LLM planning, CLEF execution and scripted mechanics.

This accepts a compatibility target and investigation, not a claim that the
existing protected uaRO executable can connect to an arbitrary private server.
Client resources do not supply the original server configuration or scripts.

## Immediate qualification

1. Establish the actual available client family/protocol and supported connection
   configuration; a filename, PE timestamp or resource version is not packet authority.
2. Identify public emulator/ruleset/content information and distinguish it from
   deployed settings or unavailable private customization. Indexed primary snippets
   are labeled as such when full pages are blocked.
3. Determine whether a supported, authorized client/server pair can be assembled,
   including any proprietary integration requirements. Do not remove or bypass
   Gepard, spoof license checks, extract protected keys or redirect public-server traffic.
4. Then choose the smallest playable server baseline and add missing public/source-
   grounded maps, NPCs, items and behavior as actual gameplay exposes the gaps.

The original unavailable MAIN20180704 archive is no longer a non-negotiable
long-term client choice. The existing profile remains the current qualified test
baseline until a concrete successor client/server pair is verified.

## Preserved boundaries

- Keep the current test world, database, volume and completed evidence unchanged.
- Do not automatically migrate from rAthena, rebuild native roles or reset data.
- Keep engine/profile-dependent implementation gated until target selection; retain
  reusable AI/domain work and the reached weight/capacity RED as existing evidence.
- Use ordinary separate Compose volumes and a project-owned human-client prefix.
- Preserve original uaRO/LATAM installations; no client launch, patching or installer
  execution is implicit in this direction.
- A client/server profile change requires targeted source/layout/framing review and
  actual isolated gameplay acceptance; it does not reset exhausted generic budgets.
