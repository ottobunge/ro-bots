## Subgoal 11 — context-rich LLM planning and fast CLEF execution (OPEN)

The user requires an LLM to investigate each agent's permitted context and author
objectives/plans, while CLEF executes validated plans through event decisions and
escalates for replanning. [[adr-021-llm-planning-clef-execution]] records this change
and overrides historical CLEF plan-authorship without rewriting accepted ADRs.
Scripts retain zero-model-call mechanical execution; free-form chat uses the LLM,
while existing premade phrases can remain CLEF choices.

Make character/rules/skills/items/known-map/private-memory/relationship/quest/schedule
information discoverable through agent-bound read-only tools, with freshness,
UNKNOWN values and provenance. More available context does not mean an unbounded
prompt, hidden live world knowledge, or another agent's experiences. Separate public
advice from received state and mechanically calculated eligibility.

**Acceptance remains open:** real LLM tool investigation and structured plans;
mechanical admission; CLEF/script native progress; bounded evidenced replan and
safe nonblocking pending behavior; plan continuity and real dashboard observability;
separate planning/chat/decision/script counters and tests proving isolation.
No provider context expansion, journal migration or live activation is implicit.
